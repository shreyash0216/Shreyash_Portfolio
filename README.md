# Shreyash Atre | Backend-Focused Engineering Portfolio

A high-density, technical portfolio designed for a **Backend Software Developer**. This project implements a dashboard-style UI inspired by developer-centric tools like GitHub and Vercel, focusing on architectural visuals and technical credibility.

## 🚀 Live Demo
**[https://shreyash0216.github.io/Shreyash_Portfolio/](https://shreyash0216.github.io/Shreyash_Portfolio/)**

## 🛠️ Technical Stack
- **Core:** HTML5, CSS3, JavaScript (Vanilla)
- **Styling:** Custom CSS with Glassmorphism and CSS Grid
- **Icons:** Lucide Icons
- **Typography:** Inter & JetBrains Mono

## 💎 Key Features
- **Split Hero Layout:** High-impact technical summary with a "System Stack" panel.
- **System Overview Panel:** Instant visual signaling of core backend competencies (Node.js, PostgreSQL, Auth, LLM Integration).
- **Engineering Skill Modules:** Structured panels focusing on logic, flow, and inference rather than just keywords.
- **GitHub Engine Stats:** Real-time visual contribution tracker and technical persistence metrics.
- **Architecture Visuals:** Custom-designed database schema visuals and API request blocks within project cards.
- **Responsive Engineering:** Fully mobile-responsive while maintaining high information density.

## 📁 Project Structure
- `index.html`: Core structure and content.
- `style.css`: Custom design tokens and engineering-themed UI components.
- `script.js`: Interactive elements and GitHub contribution grid simulation.

## 🧠 Philosophy
> “Strong fundamentals beat flashy buzzwords.”

This portfolio is built to demonstrate structured thinking, clean architecture, and backend logic specialization.
